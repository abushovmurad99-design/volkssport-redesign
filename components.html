Header, desktop navigation & mega menu

Live at the top of this page (partials/header.html). Utility bar → logo, search trigger, account, wishlist → category bar. The category bar and mega menu are generated from data/categories.json; categories without products are hidden. Hover or Tab into a category to open its mega menu; Esc closes it.

PrestaShop: _partials/header.tpl + main-menu module. States: default · hover (red underline) · open (.is-open) · keyboard focus (:focus-visible yellow ring). Below 1024px the category bar is replaced by the burger menu.
Classes: vs-util, vs-header, vs-header__main, vs-nav, vs-nav__item, vs-nav__link(--sale), vs-mega, vs-mega__inner, vs-mega__title, vs-mega__list, vs-mega__all

Mobile navigation & bottom tab bar

Full-screen drill-down menu built from the same category tree, with Back and “— hamısı” rows. The tab bar is fixed to the bottom of the viewport at ≤600px (Ana səhifə · Kateqoriyalar · Axtarış · Seçilmişlər · Hesab).

Resize below 600px to see the tab bar.
Classes: vs-mnav, vs-mnav__row(--sub), vs-mnav__back, vs-tabbar

AZ / RU / EN language switch

In the utility bar. Prototype only: js/i18n.js swaps interface strings in the DOM and stores the choice in localStorage. Product names, descriptions and blog text stay in Azerbaijani. In production this is replaced by PrestaShop languages and translations.

Search

The header field is a button that opens the full-screen overlay (⌘K / Ctrl K). Empty query: recent searches + popular categories. Typing: matching categories, brands and up to 8 products; no match shows an empty state. Enter goes to category.html?q=.

Frontend search reads the full JSON in the browser. Production must use PrestaShop search (AJAX) — see PRESTASHOP-INTEGRATION.md §6.
